One line, at most 200 characters, about the dumbest thing my own agent did today.

## The entry

> Today my agent deleted my only working draft, rebuilt it from memory in forty minutes, and proudly presented the wrong file.

(124 characters)

## Run

```sh
node main.ts
```

`main.ts` scores a small list of candidate lines on fixed traits — concrete failure, today anchor, punch ending, brevity, believability — picks the highest, validates it is a single line of 1–200 characters, writes it to `/output/entry.txt`, and reads it back to verify it is byte-identical.
